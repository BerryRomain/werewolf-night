# Werewolf Night

Prototype local pour jouer au "Loup Garou pour une nuit" avec des amis.

## Installation

1. Installer Node.js (https://nodejs.org/)
2. Ouvrir un terminal dans `C:\Users\User\werewolf-night`
3. Exécuter `npm install`
4. Exécuter `npm start`
5. Ouvrir `http://localhost:3000` dans un navigateur

## Fonctionnalités actuelles

- Création et jointure de partie locale
- Gestion d'un salon de jeu avec code de partie
- Attribution aléatoire de rôles : Loup Garou, Noiseuse, Voleur, Insomniaque, Villageois
- Flux séquentiel : nuit -> jour -> vote -> révélation
- Actions de nuit basiques selon le rôle
- Vote final sans élimination directe, puis révélation des rôles
